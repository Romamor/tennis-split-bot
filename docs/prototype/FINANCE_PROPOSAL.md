# Согласованный финансовый интерфейс

Интерактивный макет: [finance-proposal.html](finance-proposal.html).
Поведение перенесено в Kotlin; состояние установки указано в
[документации выпуска](../DEPLOYMENT_STATUS.md).

«Мои финансы» → выбранная группа (при единственной выбор пропущен):

- Перевести / Принять платёж — один ряд.
- Баланс группы — отдельный ряд.
- История переводов — отдельный ряд.
- У администратора: Записать перевод за участников.
- Назад — главное меню.

Сумма без подписи «Баланс»: плюс — «оплачено тобой за других участников группы»,
минус — «оплачено за тебя другими участниками группы». Ожидание отдельно показывает
количество и сумму; оно не меняет баланс. Цвет в Telegram реализован встроенными
цветными элементами; произвольное окрашивание текста из HTML-макета недоступно.

## Перевести

Готовые предложения по три, с пояснением: бот подобрал переводы для всей группы,
стараясь уменьшить их количество. Ниже «Записать свой перевод», даже если
предложений нет. Выбор своего получателя и баланс группы используют одну таблицу:
«Участник / Баланс», по 15. Профиль открывается по имени, баланс — получатель перевода без заранее указанной суммы.
Своя строка не позволяет отправить перевод самому себе.
Ненулевые балансы по убыванию, нули после них; в балансе показаны только участники неотменённых тренировок этой группы.
В выборе получателя доступен текущий известный состав и связанные с историей аккаунты.
Из выбора получателя «Назад» возвращает к предложениям на прежнюю страницу;
из баланса — к финансам. Полной истории навигации нет.

## Сумма

Одна карточка для готового и своего перевода. От кого / кому с текущими балансами
в скобках, сумма, объяснение подтверждения, строка подсказки ввода.
Синяя «Перевод отправлен» сверху; далее «Округлить», +50 / +100 и −50 / −100,
«Предлагается ботом N ₽» при наличии расчёта этой пары, «Ввести сумму сообщением»,
«Назад / Отмена». «Отмена» красная. Кнопки имеют значки.
Недоступные кнопки отключаются, основные строки не скрываются при смене суммы.
Геометрию и переносы определяет клиент Telegram; точную высоту бот задать не может.

Округление до ближайших 100 ₽: 49 → 0, 50 → 100, 123 → 100, 150 → 200.
Доступно после выбора рекомендации или баланса, не возникает от обычных ± или
ввода произвольной суммы. Нулевая сумма не сохраняется. Рекомендация берётся
из текущего расчёта, включая резервирование неподтверждённых переводов; она
не зависит от пути входа. При совпадении суммы кнопка остаётся отключённой.
«Ввести сумму сообщением» показывает подсказку на текущей карточке. Только
отправка числа обновляет сумму; перевод ещё не записан. Нет отдельного экрана,
«Продолжить», кнопок сброса, «По балансу» или «До округления».

## Запись, отмена и правка

Обычная отправка создаёт ожидание. Только «Да, получил» у получателя создаёт
проводки. Одинаковые отправитель / получатель / сумма за сутки требуют уточнения
повтора. Административная запись сразу учитывается и содержит указание автора.

Отправитель может изменить сумму или отменить только свой ожидающий перевод. Администратор может отменить
любой перевод и изменить его сумму при любом статусе. Подтверждённая правка
меняет баланс на разницу, отмена снимает влияние записи. Правка ожидания не
подтверждает его; правка отменённого не восстанавливает. Все действия проверяют
группу, актуальные права и версию записи. История сохранена, в деталях видны
автор и последние пять изменений; административные правки отмечены в списке.
До подтверждения в деталях показаны текущие балансы сторон, без действий по нажатию.

## История и скорость

Все участники видят «Мои / Все», по 10 переводов. Чужой просмотр не даёт права
правки. «Назад» сохраняет режим и страницу, смена режима сбрасывает страницу.
Приём — по три записи. Ожидающие переводы резервируют предложения; отмена
освобождает резерв, подтверждение переносит сумму в баланс без двойного учёта.

Страница истории загружается одним SELECT, без отдельного запроса на запись.
Баланс и рекомендация черновика читаются одним согласованным снимком SQLite,
расчёт выполняется один раз на отображение. Кнопки сохраняются одним пакетом.
Изменение суммы обновляет только личную карточку, не публикует сообщение в группу
и не вызывает проверку каждого участника в Telegram. Новых зависимостей нет.
Автоматическая проверка: `FinanceFlowTest`, `PaymentCorrectionTest`,
`FinanceServiceTest`; проверка функций макета: `node docs/prototype/check-finance-amounts.cjs`.
Внешний вид в реальном клиенте Telegram проверяется отдельно.

Личная сумма в главном финансовом экране — активный цветной элемент, чтобы
Telegram не приглушал её. Нажатие обновляет тот же экран; перевода не создаёт.

Финансовые сообщения используют заголовок `h3`, отдельные абзацы данных и
пояснения; сумма черновика — отдельный заголовок `h1`. Форматирование выполняется локально,
без новых запросов к базе или Telegram. Тексты обычного представления сохранены.

В таблицах баланса и выбора участников два столбца: «Участник / Баланс».
Подсказка: «Нажми на имя для профиля, на баланс — для перевода». Нулевой
чужой баланс тоже кликабелен; свой не предлагает перевод самому себе.

История переводов — только таблица, без дублирующих кнопок записей ниже. Имена
открывают профили, остальные поля — карточку с доступными действиями. Страница
и режим возвращаются после просмотра.

Неуспешная проверка членства не создаёт участника группы. Старые отсутствующие
аккаунты без игр и ненулевого баланса скрыты; история и расчёты сохраняются.

«Баланс группы» показывает только отмечавших участие хотя бы в одной
неотменённой тренировке этой группы. Членство в чате само по себе не добавляет
в список. Выбор получателя своего перевода использует известный доступный состав
группы; оформление таблицы и подсказка остаются общими.

«💰 Принять платёж» без счётчика: отключена и нейтральная при отсутствии
ожидающих получения переводов, зелёная (`success`) при их наличии. Состояние
берётся из уже загруженной сводки выбранной группы при отображении экрана;
дополнительных запросов и опроса по таймеру нет. Количество остаётся в тексте
сводки, но не в подписи кнопки.

При успешном ручном вводе сумма меняется в текущей карточке над кнопками;
сообщение пользователя с числом ставится в существующую очередь удаления.
Удаление выполняется фоном после доставки карточки и повторяется при временном
сбое, не задерживая её обновление. Новый перевод вводом не создаётся.
Сумма выделена отдельным заголовком `h1` без блока цитаты и центрирования.
Это самый крупный относительный размер заголовка Telegram; точный шрифт выбирает клиент.
В макете сумма — 32px, жирная, слева; это иллюстрация, а не гарантия размера в Telegram. В колонке «Играл» числа
и заголовок выровнены вправо, у отменённых пусто. Кнопка «Предлагается ботом»
возвращает текущую рекомендуемую сумму и остаётся отключённой при совпадении.

Переход из таблицы балансов выбирает только получателя; сумма нового своего
перевода не заполнена (`— ₽`), запись и округление отключены. Это действует
и при ненулевом балансе получателя. Готовое предложение начинает с рассчитанной
суммы; её можно явно выбрать кнопкой «Предлагается ботом N ₽» и в свободном вводе.

Отправитель может изменить сумму своего перевода до подтверждения получателем,
с отметкой автора правки. Изменение сохраняет ожидание и корректирует резерв;
проводок пока нет. После подтверждения изменение доступно только администратору.
Получатель подтверждает версию, которую видел: после правки старая кнопка
попросит открыть актуальную сумму. Отмена учтённого перевода меняет статус
`transfers` на `CANCELLED`, добавляет действие со снимками до/после и обратные
`balance_entries`; старые проводки сохраняются для истории.
