# Произвольные платежи — предложение для согласования

Статус: только интерактивный макет. Финансовое поведение бота и схема базы
не изменены. [Пройти меню](finance-proposal.html).

После выбора группы «Мои финансы» содержат:

- «Отправить платёж» и «Принять платёж(N)» в одной строке.
- «Другой платёж» и «История платежей» в одной строке.
- «Баланс группы» отдельной строкой.
- Для администратора — отдельную кнопку «Записать платёж за участников».
- «Назад».

«Должники» удалены. N — число всех ожидающих принятия платежей текущему
пользователю в выбранной группе, независимо от страницы списка. Счётчик
уменьшается после принятия; при отсутствии платежей показано «Принять платёж(0)».
В списке получателей один аккаунт на строку; в интерактивном просмотре можно
сравнить с двумя.

## Обычный участник

«Другой платёж» → «Кому» → сумма → «Платёж отправлен» → ожидание.
Отправитель — текущий пользователь. Получатель — другой известный боту участник
выбранной группы, независимо от его баланса или прошлых тренировок. Сумма
положительная, в целых рублях. Бот только записывает факт перевода денег.

На шаге суммы бот показывает отправителя, получателя и просьбу написать сумму
в рублях. Под сообщением — «Назад» / «Отмена», ниже — обычная строка ответа
с кнопкой отправки. Внутри сообщения полей ввода нет. Кнопка отправки или Enter
ведут к просмотру перевода; возврат сохраняет сумму, ошибка не стирает ввод.

Баланс меняется после «Принять платёж» → выбранный перевод → «Да, получил»
у получателя. Ожидающая сумма исключается из предложений отправки; если после
новой тренировки остаётся дополнительная сумма, она может появиться отдельно.
Повтор тех же отправителя, получателя и суммы за сутки требует уточнения:
«Это ещё один платёж?» → «Да, это ещё один» либо возврат. Предыдущий перевод
можно посмотреть. Назад сохраняет сумму; отмена возвращает в финансы без записи.

## Администратор

Отдельная кнопка «Записать платёж за участников» видна только администраторам
текущей группы (назначенным и администраторам Telegram).
Путь: «От кого» → «Кому» → сумма → просмотр реквизитов → «Записать платёж».
Можно выбрать любые два разных аккаунта из списка участников этой группы.

Нажатие «Записать платёж» сразу меняет баланс. Нет подтверждения получателем,
стадии ожидания и оспаривания. Просмотр реквизитов перед записью — часть ввода,
не отдельная процедура подтверждения участниками. Совпадение за сутки показывает
предупреждение на том же экране, без дополнительного шага. В истории указано,
какой администратор внёс запись. Обычная отправка администратором от себя остаётся
доступна через «Другой платёж» и подчиняется обычному подтверждению получателем.

## Баланс и проверка

«Баланс группы» показывает таблицу всех ненулевых балансов, а нулевые — для
тех, кто участвовал в тренировках. Ненулевые суммы отсортированы по убыванию:
сначала положительные, затем отрицательные (например: +450, +75, −150, −300).
Все нулевые идут после ненулевых. При равной сумме — порядок имён по алфавиту.
Сортировка применяется ко всему списку до разбивки на страницы.
Ожидание не меняет эту таблицу. Строки чередуются,
как в карточке тренировки; по пять на страницу. Выбор аккаунтов — по шесть,
отправка и принятие — по три. История — пять записей с переходом к деталям.

Макет содержит две независимые группы и три роли. Переключение роли позволяет
подтвердить платёж получателем; данные сохраняются до перезагрузки страницы.
Вторая группа показывает, что административные права принадлежат группе.
Проверки `check-finance-proposal.cjs` проходят обычную отправку, подтверждение,
дубли, административную запись, балансы, роли, изоляцию, страницы и возвраты.
Полные проверки настоящей базы и обработки Telegram потребуются при реализации.
