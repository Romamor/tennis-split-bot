# Итог правок интерфейса

8 сентября 2026. Правки завершены, проверены 132 тестами и установлены на VDS.
Версия приложения historical-release. Сведения о проверке и резервной копии —
в [DEPLOYMENT_STATUS.md](DEPLOYMENT_STATUS.md).

## Результат

- Главное меню: тренировка, долги, перевод; дополнительные действия отдельно.
- Запись тренировки: игроки → оплаты → сохранение без обязательного просмотра расчёта.
- Название группы на экранах и запросах ввода; смена группы и /groups.
- Состав из прошлой тренировки берётся только из выбранной группы, дата указана на кнопке.
- Все растущие списки перелистываются, включая личные незавершённые записи.
- История показывает короткие кнопки; длинные подробности правки тоже имеют страницы.
- Исправления учтённой тренировки разрешены любому текущему участнику именно её группы.
- Проверены изоляция финансов, истории, посещаемости, черновиков, текстовых ответов и прав разных групп.
- В README описаны все 21 таблица. Ревью схемы сохранено в DATABASE_REVIEW.md.

## Дальше

Предлагается остановиться на проверке нового интерфейса пользователем через /menu.
Схема базы не менялась; объединение таблиц, очистка временных данных и перенос
пагинации в SQL остаются отдельными предложениями. VPN и настройки памяти не менялись.
