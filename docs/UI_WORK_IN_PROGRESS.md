# Точка продолжения: упрощение интерфейса

8 сентября 2026. На время ревью базы была сохранена эта точка продолжения; после ревью работа возобновлена с уточнёнными правами редактирования.

## Сделано локально

- Три основных действия в меню; игроки → оплаты → запись без обязательного просмотра расчёта.
- Название группы на экранах и запросах ввода; смена группы и /groups.
- Список групп включает ранее открытые и настроенные пользователем группы, с повторной проверкой доступа.
- Повтор состава указывает дату конкретной учтённой тренировки той же группы.
- Меньше вспомогательных кнопок, отдельное сохранение на потом, оплаты только выбранных игроков по умолчанию.
- Сохраняется страница при вводе оплаты; чистая устаревшая карточка обновляется при повторном открытии.
- Дополнены проверки изоляции финансов, истории, посещаемости, черновиков, доступа и текстовых ответов между группами.

## Состояние

Прошли все 132 теста и build installDist, включая проверки новых прав редактирования. Изменены BotUi.kt, DraftEditing.kt, TelegramBot.kt, TelegramStore.kt и TelegramBotTest.kt. Изменения не закоммичены, не отправлены в GitHub и не установлены на сервер. Схема базы не менялась.

На сервере остаётся версия historical-release. Проверка только чтением показала: test зарегистрирована с нулём участников, прежние игроки находятся в группе «Отладка бота расчетов»; личный диалог всё ещё был привязан к прежней группе. Данные между группами не переносились.

## Следующий шаг

Ревью и описание всех таблиц в README готовы, инструкция Telegram обновлена. Следующий этап — итоговая сборка, резервная копия и установка. Исправления учтённой тренировки разрешены любому текущему участнику именно её группы. Не менять схему и не разворачивать рефакторинг базы без принятого решения. Не трогать VPN и настройки памяти сервера.

Дополнительно: удалена дублирующая кнопка создания; список тренировок объединён и перелистывается целиком. История стала коротким списком кнопок. Пагинация добавлена похожим переводам, восстановлению сообщений и длинным подробностям правки. Проверка прав организаторов и самого бота в разных группах вынесена в отдельный тест.
