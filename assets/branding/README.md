# Аватар Telegram

Дополнительный вариант: [«Атака титанов»](telegram-avatar-aot-v3.png),
[описание и промпт](AVATAR_AOT.md).

[telegram-avatar-v1.png](telegram-avatar-v1.png) — квадратный аватар бота:
ракетка для настольного тенниса, мяч и монета на синем фоне. Без текста,
основные элементы помещаются внутри круглого обрезания аватара.

Создан 6 октября 2026 года встроенным инструментом `image_gen`.
Размер полученного PNG: 1254 × 1254. Исходник сохранён без преобразования.
Загрузка в профиль Telegram выполняется отдельно; наличие файла в репозитории
не меняет действующий аватар бота.

## Промпт

```text
Use case: logo-brand. Create a single polished square avatar image for a Telegram bot that splits the cost of table-tennis sessions among friends. A bold, friendly, immediately recognizable emblem: one table-tennis paddle and a small ping-pong ball, with a simple coin integrated into the composition to convey shared expenses. Clean modern illustrated icon, crisp silhouettes, restrained subtle depth, very few shapes, strong contrast. Blue background consistent with the bot's interface, light paddle with a blue face and warm coin accent. The main symbol should be large but fully contained inside a central circular safe area with generous edge clearance for Telegram's circular crop. Solid full-bleed background, not transparent. No words, letters, numbers, currency symbols, watermark, UI frame, mockup, or extra decorative elements. Deliver one finished 1024x1024 icon, not a sheet of alternatives.
```
